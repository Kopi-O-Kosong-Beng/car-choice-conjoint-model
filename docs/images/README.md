## vault-graph.png (referenced by README.md, not yet added)

To capture it:
1. Open the REPOSITORY ROOT as an Obsidian vault (File > Open folder as vault).
2. Press Ctrl+G for graph view.
3. Optional, makes it far more readable:
   - Filters: set the search box to `path:Vault` so only notes show, not every PDF.
   - Groups: add a group `path:Vault/Competition` in one colour and
     `path:Vault/Topics` in another - the competition cluster then reads clearly.
   - Display: turn up "Link thickness" and enable "Text fade threshold" so labels show.
4. Win+Shift+S to snip, save here as `vault-graph.png`.

Dark mode screenshots read better on GitHub for most viewers.
